# Tracker state is home presence; the area is an attribute

The camera tracker is a presence (connection) tracker in `zone.home`, like a router or beacon: its state is "home" while a sighting is current and "unknown" otherwise (TTL expiry or authoritative demotion, ADR 0004), with `in_zones: [zone.home]` while home. The room moves to attributes: `area` (live display name, only while the sighting is current), `last_location` (live display name, retained) and `area_id`. Rationale: HA's person entity copies a GPS-type tracker's state verbatim, so an area-name state made a linked person "Kitchen" rather than "home", left them out of `zone.home` and broke "is home" automations; a connection tracker reporting zone membership is also the person entity's highest-priority source. Supersedes the "tracker state carries the area display name" part of ADR 0003. Rejected alternative: keeping the area-name state and asking users to template a separate sensor - it leaves the default person linking broken.
