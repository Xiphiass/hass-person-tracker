# Handoff check when a camera loses sight

A trigger only detects on an off -> on edge (ADR 0005). A Detection that stays on because people are already in a room fires no edge for a Person who walks in, so that Person keeps the area of the camera that last saw them until the sighting expires. A presence re-check (ADR 0007) does not close this gap: it runs shortly before expiry, which is up to a whole TTL late, and it asks the camera the Person left. Instead, when a camera's Detection goes off (none of its triggers is on) and stays off for a few seconds, each Person that camera last saw, with a current sighting and not reported away by the authoritative tracker, is looked for on every other camera whose Detection is on. The question names those Persons only and is worded like a re-check ("they just left another camera's view, are they here now?"). The camera's own on edge within the delay cancels the check, so a flickering sensor costs nothing. The check ignores the cooldown but claims it, like a re-check: the active camera's recent run was for the people already there, and if that run had found the Person, their last camera would already have changed and they would not be looked for. A confirmation is a normal sighting, corroborated as usual (ADR 0009): the active Detection chose the camera, not the supporting tracker. A miss or a failed run changes nothing, is not retried, and never saves an Unknown snapshot. If several active cameras confirm the Person, the last answer wins. A global option, on by default, turns it off. Rationale: losing sight is the moment a Person is most likely to appear elsewhere, the cameras worth asking are exactly the ones that see someone, and the question costs one AI call per active camera only when a camera that last saw someone goes quiet. Trade-off: it relies on the last camera's Detection going off. A Person who leaves one occupied room for another, where neither Detection ever goes off, is still not caught; re-running detection while a Detection stays on would cover that, at a steady cost per busy room, and is left for later. Rejected alternatives: searching the active cameras when a re-check misses (correct, but only near expiry); and asking cameras in neighbouring areas (needs an adjacency map to configure, and a neighbouring camera with no Detection on is unlikely to see anyone).
