# Configuration is a UI config entry with an explicit camera-to-trigger map

All integration configuration (people, camera->trigger map, optional AI task entity, optional per-person authoritative tracker and TTL) lives in a UI config entry, not YAML; entity pickers keep references valid as entities change. The camera->trigger map is explicit - each camera names its exact trigger binary sensor(s), with no same-device auto-detection default. Rejected alternative: auto-picking person/motion sensors from the camera's device - UniFi cameras expose several detection sensors (person, motion, sound) and the user must choose which one drives tracking; implicit selection would track on the wrong trigger. Reference images are the one thing outside the entry: files dropped into per-person config-dir folders (person_tracker/people/<person>/), picked up at setup and on reload.
